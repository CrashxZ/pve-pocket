# UI roadmap

## 0.1.2-alpha candidate — unreleased

The follow-up to [v0.1.1-alpha](https://github.com/CrashxZ/pve-pocket/releases/tag/v0.1.1-alpha) focuses on presentation, not new PDM management capabilities:

- Show unavailable metrics clearly rather than suggesting zero usage or an unknown storage driver is a measured value.
- Make remote and node names easier to scan while preserving their underlying identities.
- Reduce PDM-only clutter from unsupported power and shell controls, while keeping the read-only scope clear.
- Improve refresh controls, contrast and consistency across overview, host, guest and detail screens.

Implementation is in progress. The candidate has **not been released**; screenshots in the [README](../README.md#screenshots) show v0.1.1, not the planned UI. Device review and regression checks are required before publication. Scope and timing may change.

PDM power routing and built-in terminal streaming remain unsupported; this UI work does not promise to enable them.
